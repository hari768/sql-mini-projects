# Shopeasy E-Commerce SQL Analysis - 4

## 📌 Project Overview

This project focuses on analyzing an e-commerce database called **Shopeasy** using PostgreSQL and SQL.

The goal is to extract meaningful business insights from customer orders, products, and reviews.

---

## 🛠 Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

---

## 🗄 Database Tables

1. Customers
2. Orders
3. Order_Items
4. Products
5. Reviews

---

## 📊 Business Questions Solved

### Task 1: Calculate Total Revenue
### Task 2: Identify Top Selling Products
### Task 3: Calculate Average Order Value (AOV)
### Task 4: Calculate Customer Lifetime Value (CLV)
### Task 5: Identify Customers Who Have Not Purchased Recently
### Task 6: Show Most Recent Review For Each Product
### Task 7: Identify Top Rated Products
### Task 8: Calculate Discount Based On Order Value
